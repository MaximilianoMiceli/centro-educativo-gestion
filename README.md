# centro-educativo-gestion

DOCUMENTACIÓN:

Contiene todos los análisis del proyecto (requerimientos, arquitectura, clasificación, casos de uso)
Permite que nuevos miembros del equipo entiendan el contexto completo del sistema

DISEÑO:

Diagramas de la arquitectura (ERD, casos de uso, capas)
Wireframes de la interfaz de usuario
Proporciona la visión visual del sistema

BACKEND:

Código del servidor (Node.js/Express)
Controllers: manejan las peticiones HTTP
Services: lógica de negocio (validaciones, inscripciones, reportes)
Models: definición de entidades de la BD
Middleware: autenticación, autorización, auditoría
Routes: endpoints de la API

FRONTEND:

Código React
Components: componentes reutilizables (formularios, tablas, etc.)
Pages: páginas principales (Login, Dashboard, Gestión de Alumnos, etc.)
Services: llamadas a la API

DATABASE:

Scripts SQL para crear tablas (Alumno, Docente, Usuario, Log_Auditoría, etc.)
Migraciones para cambios de estructura
Backups automáticos
